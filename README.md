# IT'S WHATEVER — the documentary

> "I hate your workflow culture, nerds" — this repository, as a description of itself

For seven months, the main branch of this repository contained exactly one file: `.gitkeep`, zero bytes. It was the entire project. Two pull requests arrived during that time — 44,584 bytes and 63,457 bytes of scaffolding for a video AI that was never built, around a model that was never pulled — and sat open, unmerged, while the main branch kept the faith.

This repository now contains a film about that.

**▶ [its-whatever-the-movie-v2-2026-11-24.mp4](its-whatever-the-movie-v2-2026-11-24.mp4)** — 2 minutes 12 seconds. The empty main branch, the confession, the 874-byte kitchen, and the only honest release date in documentary history. *It's Whatever. Coming soon to a main branch near you. Eventually. Probably not.*
